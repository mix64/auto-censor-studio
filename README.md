# Auto Censor Studio

PNG画像の性器を自動で検出し、その輪郭に沿ってモザイクをかけるWindows用のツールです。
検出も輪郭の抽出もPC内で実行し、画像を外部へ送信しません。
複数の画像を開いたときは、一括で検出してから1枚ずつ確認して書き出せます。

自動検出には検出漏れと誤検出があります。
候補が0件だったことは、修正が不要だという判定ではありません。
書き出す前に、画像の全体と細部を自分の目で確認してください。

## セットアップ

`dist\AutoCensorStudio\AutoCensorStudio.exe` をダブルクリックすると起動します。
exe には Python と依存ライブラリが含まれているので、Python をインストールしていないPCでも動きます。
別のPCで使うときは、`dist\AutoCensorStudio` フォルダーごとコピーしてください。exe だけを取り出しても起動しません。

初回の起動時だけ、検証済みのモデル（約90MB）をダウンロードするのでネット接続が必要です。
モデルは `%LOCALAPPDATA%\AutoCensorStudio\models` に保存します。
画像の処理そのものはオフラインで動作します。

exe を作り直すには、Python 3.12以降で次のコマンドを実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe tools\build_exe.py
```

ソースから直接起動するときは `.\.venv\Scripts\python.exe -m auto_censor_studio` を実行します。

## 1枚の画像を処理する

1. 「開く」でPNGを選ぶか、画像をウィンドウにドロップします。
2. 「自動検出」を押します。男性器と女性器の位置を検出し、それぞれの輪郭を抽出して、その内側にモザイクをかけます。
3. 検出されなかった箇所があれば、「範囲追加」を押して対象を大まかに四角く囲みます。囲んだ範囲から輪郭を抽出し、選択モードに戻ります。
4. 操作バーの「粗さ」でモザイクのブロックサイズを、「余白」で輪郭から外側へ広げる幅を調整します。
5. 「保存」で別名を付けて書き出します。形式はPNGかJPEGを選べます。元画像に上書きしたいときは、後述の「元画像に上書き保存する」を使います。

粗さの初期値は16ピクセル、余白の初期値は10%です。粗さは1〜1,000ピクセルの範囲で変更できます。
大きな画像では16ピクセルでも細部が判別できることがあります。粗さ欄のツールチップに出る目安（長辺の1/100）を参考に、輪郭の形も含めて細部が判別できなくなる強さに調整してください。

## 範囲を修正する

範囲の枠は初期状態では表示しません。「…」の「枠を表示」をオンにすると、抽出した輪郭の点をドラッグして形を調整し、内側をドラッグして移動できます。
輪郭の抽出に使うMobileSAMは一般物体向けのモデルなので、絵柄や重なりによっては境界を外すことがあります。

輪郭を外したときは、手で描き直せます。

- **手描きで囲む**：右上の「…」から選び、ドラッグで輪郭を描きます。ドラッグを離すと閉じた範囲になり、Escで取り消せます。
- **輪郭を描き直す**：範囲を右クリックして選び、選択中の範囲を手描きの輪郭で置き換えます。
- **輪郭を再推定**：四角い範囲を右クリックして選び、その範囲から輪郭を抽出し直します。
- **モザイクから外す部分を囲む**：手や小物など、性器に重なっている別の物まで範囲に入ったときに使います。範囲を右クリックして選び、外したい部分をドラッグで囲みます。囲んだ部分は余白を広げたあとで範囲から外すので、元の画素のまま残ります。「外した部分を元に戻す」で、その範囲から外した部分をすべて取り消せます。

輪郭を確実に抽出できなかった範囲は、四角いまま残して画面下部にその件数を表示します。
範囲を削除するには、右クリックして「選択範囲を削除」を選ぶか、Deleteキーを押します。

「戻す」とCtrl+Zで取り消せるのは、範囲の追加や変形などの編集だけです。
粗さ、余白、検出の設定の変更は取り消しの対象外です。

## 複数の画像をまとめて処理する

1. 「開く」で複数のPNGを選択します。あとから追加することもでき、同じ画像は二重に登録されません。上限は1,000枚です。
2. 画面下部の「一括処理」を押すと、未処理かつ未確認の画像を順に検出し、輪郭を抽出します。「停止」で中断しても処理済みの画像の結果は残り、もう一度押すと残りの画像を処理します。
3. 一覧か前後のボタンで画像を1枚ずつ表示し、必要なら範囲を修正します。処理が終わった画像は、ほかの画像を処理している最中でも手描きや点の移動で修正できます。自動検出と輪郭の自動抽出は、一括処理が終わるまで使えません。
4. 「確認して次へ」で表示中の画像を確認済みにし、次の確認できる画像へ進みます。候補が0件の画像も確認が必要です。確認済みの画像でも、輪郭、粗さ、余白のいずれかを変更すると未確認に戻ります。
5. 「まとめて保存」で保存先フォルダーを選ぶと（初期値は表示中の画像のフォルダー）、確認済みの画像だけをPNGで書き出します。ファイル名は `元の名前_censored.png` で、同じ名前のファイルがあれば連番を付けます。この方法では元画像を上書きしません。

輪郭、粗さ、余白、検出の設定、取り消しの履歴は画像ごとに保持します。
画素データは表示や処理に必要な画像だけを読み込むので、大量のPNGを開いてもすべてをメモリに展開することはありません。
一部の画像で処理に失敗しても残りの処理は続き、失敗した画像は一覧に「失敗」と表示されます。

「…」の「現在の画像を一覧から外す」と「すべての画像を一覧から外す」は一覧から外すだけで、元のファイルは削除しません。

## 元画像に上書き保存する

「…」の「元画像に上書き保存」で、表示中の画像の元のPNGをモザイク済みの画像に置き換えます。
複数の画像を開いているときは、「確認済みを元画像に上書き保存」で、確認済みで範囲が1件以上ある画像をまとめて置き換えます。

どちらも実行前に確認を求めます。
上書きした画像は元に戻せないので、必要なら先に元画像のコピーを取ってください。
書き込みは一時ファイルを経由するので、途中で失敗しても元画像は壊れません。
読み込んだあとにほかのアプリで元画像が変更されていた場合は、上書きせずに失敗として知らせます。

上書きしたあとは、モザイク済みの画像を読み込み直し、範囲と取り消しの履歴を空にします。
範囲を残したまま保存するとモザイクが二重にかかるためです。
上書き前に保存した作業ファイルは、元画像の内容が変わるので開けなくなります。

## 作業を保存して再開する

「…」の「作業を保存」で、範囲の輪郭、粗さ、余白を1つのJSONファイルに保存できます。
複数の画像を開いているときは、全画像の範囲と設定、確認済みかどうかをまとめて保存します。

保存した作業は「…」の「作業を開く」で再開します。
1枚用と複数枚用のどちらの作業ファイルも開けます。
四角い範囲だけを記録した作業ファイルも読み込めます。
作業ファイルはPNGのようにドロップしても開けません。

作業ファイルには元画像のパスとハッシュを記録しています。
元画像を移動したり編集したりすると、その作業は再開できなくなります。
取り消しの履歴は作業ファイルに含まれず、再開後は最初からになります。

## 操作

- Ctrl+O：PNGを開く
- Ctrl+S：処理済み画像を保存
- Ctrl+Z：元に戻す
- Ctrl+Y：やり直す
- Delete：選択した範囲を削除
- Esc：作成中の範囲を取り消す
- マウスホイール：拡大と縮小
- Shift＋ドラッグ：表示位置の移動

## 設定と保存先

検出しきい値と分割検出の有無は、「…」の「検出オプション」で変更します。
変更は表示中の画像と、これから追加する画像の検出に適用され、画像を開く前にも変更できます。
値は次回の起動時にも引き継がれます。

「…」の「ダークモード」で配色を切り替えられます。
配色は画面にだけ適用され、画像やモザイクの内容は変わりません。

設定とモデルは `%LOCALAPPDATA%/AutoCensorStudio/` に保存します。
設定のファイルは同じフォルダーの `preferences.ini` です。
モデルの保存先は環境変数 `AUTO_CENSOR_MODEL_DIR` で変更できます。

## 入力と出力

- 入力は静止画のPNGだけで、5,000万画素までです。拡張子だけをPNGに変えたJPEGなどは読み込みません。
- 透明な部分は白い背景に合成します。
- 対応するICCプロファイルはsRGBに変換し、EXIFの向きは画素に反映します。
- 出力は元の画像と同じサイズです。元画像のメタデータは出力に含めません。
- モザイクは範囲の内側だけにかけ、輪郭の境界で元画像と混ぜることはしません。輪郭の内側にある小さな穴は埋めます。

## 検出の仕組みと限界

位置の検出にはdeepghsが公開している `anime_censor_detection` を、輪郭の抽出にはMobileSAMのONNX版を使います。
どちらのモデルもPC内のCPUで実行します。
モデルのリビジョンとSHA-256は固定してあり、ダウンロード時と読み込み時に検証します。

検出モデルは乳首も検出できますが、このツールはその結果を常に捨てます。
作業ファイルに乳首の自動検出範囲が含まれていても、読み込み時に取り除きます。
手動で追加した範囲は取り除きません。

このツールはpixivの非公式ツールです。
[pixivガイドライン](https://www.pixiv.net/terms/?page=guideline)に適合するかは判定しません。
年齢制限の設定は、投稿時にpixiv側で行ってください。
